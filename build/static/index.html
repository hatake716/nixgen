Starter files for a machine that does not have a flake yet. They go in /etc/nixos beside the hardware-configuration.nix that is already there. Pick them from the tabs on the right.

The whole disk, not a partition — /dev/sda, not /dev/sda1.

Separated by spaces or commas. wheel is what lets the account use sudo.

The release you first installed. Do not raise it to match a newer NixOS. It keeps stateful data readable across upgrades, and raising it can break things.

Everything in configuration.nix uses lib.mkDefault, so anything you also set here in nixgen wins instead of colliding with it.

First rebuild, before flakes are on
sudo nixos-rebuild switch
From then on
sudo nixos-rebuild switch --flake /etc/nixos#nixos
