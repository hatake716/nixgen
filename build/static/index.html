How this works

nixgen writes new files. The ones you already have are read at most, never changed.

  1. New machine, no flake yet? The Setup tab fills in the two a fresh install still needs: configuration.nix, the half you write by hand, and flake.nix, the way in to the whole system. Take each from the file tabs and keep all four in one directory. 
    /etc/nixos/
|-- flake.nix                   from Setup
|-- configuration.nix           from Setup
|-- hardware-configuration.nix  written when you installed; left alone
`-- generated.nix               what you build here
    flake.nix reads configuration.nix, which reads the other two. Setup prints the command that applies them.
  2. Already have a configuration.nix? Press Import configuration.nix. Your settings come back as fields you can edit.
  3. Add a setting. Open Options and type what you are after — ssh, firewall, timeZone. Click a result and it lands here.
  4. Add software. Open Packages and click what you want. It goes into environment.systemPackages.
  5. Use the file. Press Download generated.nix, put it beside your configuration.nix, add ./generated.nix to imports, then run sudo nixos-rebuild dry-build before you switch.

Closing the tab loses the form. Nothing is kept between visits, so the file is the save: download generated.nix, and Import configuration.nix brings those settings back as they were. The Setup fields are not part of it.

Check syntax finds broken Nix and nothing else — whether a value is the right type is for dry-build to say. The longer version.

使い方

nixgen は新しいファイルを作ります。今あるファイルは読むだけで、書き換えることはありません。

  1. flake がまだ無い、新しいマシンですか。 Setup タブが、インストール直後に足りない2つを用意します。手で書く側の configuration.nix と、システム全体の入口になる flake.nix です。ファイルタブからそれぞれ受け取り、4つを同じディレクトリに置いてください。 
    /etc/nixos/
|-- flake.nix                   Setup から
|-- configuration.nix           Setup から
|-- hardware-configuration.nix  インストール時に作られたもの。触りません
`-- generated.nix               ここで作るファイル
    flake.nix が configuration.nix を読み、そこから残りの2つを読みます。適用するコマンドは Setup が表示します。
  2. すでに configuration.nix がありますか。 Import configuration.nix を押してください。今の設定が、編集できる入力欄として戻ってきます。
  3. 設定を足す。 Options を開いて、探しているものを入力します — ssh、firewall、timeZone など。結果をクリックすると、ここに入ります。
  4. ソフトを足す。 Packages を開いて、欲しいものをクリックします。environment.systemPackages に入ります。
  5. できたファイルを使う。 Download generated.nix を押し、configuration.nix の隣に置いて、imports に ./generated.nix を足します。切り替える前に、sudo nixos-rebuild dry-build で確かめてください。

タブを閉じると、入力した内容は消えます。何も保存していないので、保存にあたるのはファイルです。generated.nix をダウンロードしておけば、Import configuration.nix で元のとおりに戻せます。Setup の入力欄はこれに含まれません。

Check syntax が見るのは Nix の文法だけです。値が正しい型かどうかは dry-build が答えます。詳しい説明。
